# DeepStructGenomics-NCBI v0.2.0

Cette version facilite la comparaison de deux ARN : import FASTA, validation
des séquences et résumé des positions les plus modifiées dans les rapports.

## Fonctionnalités

- Entrées locales `--fasta` et `--mutant-fasta`, une séquence par fichier,
  avec conservation de l'identifiant et de la provenance de la référence.
- Normalisation ADN → ARN pour toutes les sources ; les caractères non pris
  en charge sont signalés avec leur position.
- Résumé d'impact partagé par l'API Python, le JSON et le rapport Markdown.
- Viewer WT/mutant avec deltas, tooltips, connecteurs et exports PNG configurables.
- Démo synthétique hors ligne et illustration reproductible.

## Corrections et compatibilité

- Les colonnes PDB exportées préservent les identifiants de chaîne à la
  relecture : les couleurs affichées correspondent aux scores calculés.
- Les modes `minimal` et `molecule` démarrent avec leurs options par défaut.
- Les légendes et tooltips fonctionnent avec les versions récentes de VTK.
- Les séquences ambiguës ou invalides sont refusées au lieu d'être raccourcies
  silencieusement. Corriger la source avant de relancer le pipeline.
- Les positions des rapports Markdown et des hotspots commencent à 1.
  Les champs JSON historiques `structure.base_pairs` et
  `variant_analysis.substitutions[].position` restent comptés depuis 0.

## Validation

- 95 tests locaux réussis sous Windows / Python 3.11.
- Tests GitHub Actions réussis sous Linux / Python 3.10 et Windows / Python 3.12.
- Construction du paquet installable, démo hors ligne et export PNG vérifiés.

## Essayer la version

Depuis une copie du dépôt au tag `v0.2.0`, après création et activation d'un
environnement Python 3.10 ou ultérieur :

```bash
python -m pip install -r requirements.txt
python scripts/run_demo.py
python scripts/run_pipeline.py --fasta data/examples/reference.fasta --mutant-fasta data/examples/mutant.fasta --output-dir outputs_fasta
```

La release fournit le paquet wheel, l'archive source et une archive de résultats
de la démo avec les rapports, les structures, les scores et un export PNG.
Le fichier `SHA256SUMS.txt` permet de vérifier les fichiers téléchargés.

Les scores sont heuristiques ; les projections 3D ne sont pas des structures
atomiques validées. Cette version est destinée à l'exploration en recherche.
