## Installation et exemples hors ligne

Depuis le tag `v0.4.4`, avec Python 3.10 ou ultérieur :

```bash
python -m pip install --require-hashes --only-binary=:all: -r requirements-lock.txt
python scripts/run_demo.py
python scripts/run_pipeline.py --batch-fasta data/examples/batch.fasta --output-dir outputs_batch
python scripts/evaluate_rna.py --reference data/examples/rna_reference.json --output outputs_evaluation/metrics.json
python scripts/explore_hic.py --contacts data/examples/hic_contacts.tsv --assembly synthetic --bin-size 10000 --output-dir outputs_hic
python -m pytest
```

Le dossier des lots doit être nouveau. Une entrée FASTA invalide produit un rapport
d'erreur et un code CLI 2, sans empêcher le traitement des entrées suivantes.

## Format Hi-C

TSV UTF-8, en-tête exact : `chrom1`, `start1`, `chrom2`, `start2`, `count`.
Chaque ligne décrit un contact entre deux bins ; débuts depuis 0, multiples de
`--bin-size`, intervalles `[start, start + bin_size)`. `--assembly` indique
l'assemblage source ; cet outil ne vérifie pas les longueurs des chromosomes.
Les poids doivent être finis et non négatifs. Un contact n'apparaît qu'une fois :
les répétitions et leur symétrique sont refusés. Préparer une seule moitié de la
matrice en amont. Les poids des diagonales comptent une fois dans la couverture.

Le JSON contient provenance/empreinte, poids total/cis/trans/diagonal, fraction
cis, couverture des bins, poids par distance cis et contacts les plus pondérés
(`--top-k`, défaut 10). Les ratios de somme nulle valent `null`.
Les bins absents ne sont pas interprétés comme des observations à zéro.
Les formats `.hic` et `.cool` doivent être convertis en amont ; aucun téléchargement
automatique, équilibrage ICE/KR, appel de boucles/TAD ou reconstruction 3D n'est effectué.

## Portée scientifique

Les exemples ARN et Hi-C sont synthétiques. Les scores ARN vérifient l'outillage,
pas la validité biologique. Une évaluation sur un corpus expérimental indépendant
et une comparaison externe réellement exécutée restent nécessaires.
Le module Hi-C conserve les poids fournis, sans corriger les biais expérimentaux ;
les fractions descriptives ne constituent pas une normalisation de matrice.
Voir la [publication sur la normalisation des cartes de contacts](https://pubmed.ncbi.nlm.nih.gov/34415528/).
Les structures pseudo-3D du pipeline restent illustratives.
