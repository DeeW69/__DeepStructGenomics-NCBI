# DeepStructGenomics-NCBI v0.3.0

Cette version simplifie l'ouverture des résultats et leur exploitation dans
des tableurs ou notebooks.

## Fonctionnalités

- `scripts/view_3d.py --manifest` charge les structures et scores depuis le
  manifeste et choisit automatiquement le mode de visualisation. Les chemins
  relatifs privilégient le dossier du manifeste ; les anciens chemins et les
  dossiers déplacés sont également pris en charge, y compris les séparateurs Windows.
- Export des hotspots dans `<run_id>_hotspots.csv` et `visualization/hotspots.csv`,
  avec les colonnes `position`, `reference`, `mutant`, `delta`, `abs_delta`.
  Les positions commencent à 1. Sans hotspot, le CSV conserve son en-tête.
- Réglages CLI : `--top-k`, `--min-abs-delta` (alias `--delta-threshold`) et
  `--base-pair-threshold`. Les valeurs par défaut restent 10, 0,1 et 0,2.
- Politique de publication documentée dans `VERSIONING.md`.

## Installation et exemple

Depuis une copie du dépôt au tag `v0.3.0`, utiliser le Python d'un environnement
virtuel avec Python 3.10 ou ultérieur :

```bash
python -m pip install --require-hashes --only-binary=:all: -r requirements-lock.txt
python scripts/run_demo.py
python scripts/view_3d.py --manifest outputs_demo/offline_demo/visualization/visualization_manifest.json --export outputs_demo/overlay_delta.png --export-only
python scripts/run_pipeline.py --fasta data/examples/reference.fasta --mutant-fasta data/examples/mutant.fasta --top-k 5 --min-abs-delta 0.2 --base-pair-threshold 0.3 --output-dir outputs_fasta
```

Les options existantes et les champs JSON historiques sont conservés. Le
manifeste ajoute la référence au fichier CSV. Les dépendances restent verrouillées
comme en v0.2.1 ; l'installation du wheel seul n'applique pas ce verrou.

## Validation et fichiers

- 147 tests locaux sous Windows / Python 3.11.
- CI Linux / Python 3.10 et Windows / Python 3.12.
- Construction et installation du paquet, démo, CSV et export PNG via manifeste vérifiés.
- Wheel, archive source, archive des résultats de la démo et `SHA256SUMS.txt`.

## Suite de la roadmap : v0.4.x

Les pistes suivantes sont prévues pour évaluation et développement, sans être
incluses dans cette release : cache NCBI avec provenance et rafraîchissement,
FASTA par lots, évaluation des prédictions ARN et exploration des contacts Hi-C.

Les scores sont heuristiques et les projections 3D ne sont pas des structures
atomiques validées.
