# v0.4.1 — Cache NCBI

Le pipeline conserve les séquences normalisées et métadonnées dans `data/cache`.
La provenance inclut accession demandée/résolue, base NCBI, URL, date UTC et
SHA-256 de la séquence normalisée. Les paramètres email/API ne sont pas stockés.

`--cache-dir chemin` choisit le cache ; `--refresh-cache` force le téléchargement.
Sans rafraîchissement, une entrée valide est réutilisée sans réseau, sans expiration
automatique. Une accession non versionnée peut donc rester ancienne : rafraîchir
explicitement pour retrouver la version courante. Les écritures sont atomiques ;
un échec réseau conserve le cache précédent mais fait échouer le rafraîchissement.

L'API `NCBIClient(cache_dir=Path(...))` active le cache ; sans ce paramètre,
le client autonome conserve son comportement historique. Tests hors réseau dans
`tests/test_ncbi_cache.py` ; aucune nouvelle dépendance.
