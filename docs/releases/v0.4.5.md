# v0.4.5 — Benchmark ARN expérimental et ViennaRNA exécuté

30 annotations issues du sous-ensemble PDB de bpRNA-1m, sélectionnées avant les
prédictions, remplacent le seul exemple synthétique pour l'évaluation publiée.
La provenance, les empreintes et les règles de sélection sont dans
[le guide du corpus](../../data/benchmarks/README.md).

```bash
python -m pip install --require-hashes --only-binary=:all: -r requirements-lock.txt
python -m pip install --require-hashes --only-binary=:all: -r requirements-research-lock.txt
python scripts/evaluate_rna.py --reference data/benchmarks/bprna_pdb.json --viennarna --output outputs_benchmark/metrics.json
```

ViennaRNA 2.7.2 est effectivement exécuté via son API `fold_compound.mfe`, à 37 °C,
dangles=2, sans contrainte, avec paramètres thermodynamiques par défaut.
Le rapport conserve les structures prédites, énergies, versions et paramètres.
L'option est facultative : le pipeline et l'évaluation historiques fonctionnent
sans les dépendances de recherche.

[Résultats détaillés archivés](../benchmarks/v0.4.5_rna.json).
ViennaRNA obtient ici un F1 supérieur au modèle interne. Ce constat porte sur ce
petit corpus, sans démontrer une performance générale ou clinique. Aucun paramètre
n'a été optimisé sur ses références ; les biais de sélection restent documentés.

Validation : corpus traçable, préparation déterministe, erreur de dépendance
manquante, exécution réelle et reproduction des structures/métriques archivées.
Les dépendances optionnelles sont verrouillées séparément avec empreintes.
