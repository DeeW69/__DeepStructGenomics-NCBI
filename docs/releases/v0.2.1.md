# DeepStructGenomics-NCBI v0.2.1

Cette version de stabilisation rend l'environnement de validation reproductible,
fiabilise la lecture des réponses NCBI et documente la numérotation des positions.
Elle succède à v0.2.0 sans modifier les formats de sortie ni les options de la CLI.

## Changements

- Dépendances du pipeline et des tests verrouillées avec versions exactes,
  marqueurs Python/plateforme et empreintes SHA-256. Le même verrou est utilisé
  par les tests Linux et Windows.
- Correction des résumés NCBI contenant `null`, une liste ou une entrée non objet :
  une séquence valide reste exploitable avec des métadonnées vides. Les erreurs
  HTTP et réseau continuent à interrompre l'analyse avant l'export.
- 37 tests supplémentaires hors réseau : réponses vides, erreurs HTTP,
  délais dépassés, erreurs de connexion et comportement de la CLI.
- Guide `docs/coordinates.md` : indices Python/JSON depuis 0, positions des
  rapports Markdown et des fichiers de visualisation depuis 1, exemples vérifiés
  sur la démo et conversion des paires pour les connecteurs 3D.
- Guide `docs/dependencies.md` pour installer et mettre à jour le verrou ;
  collecte pytest limitée au dossier `tests/`.

## Installation et mise à jour

Depuis une copie du dépôt au tag `v0.2.1`, créer un environnement Python 3.10
ou ultérieur, puis utiliser le Python de cet environnement :

```bash
python -m pip install --require-hashes --only-binary=:all: -r requirements-lock.txt
python -m pip check
python scripts/run_demo.py
```

Le verrou et les guides sont inclus dans l'archive source. L'installation du
wheel seul utilise les plages de dépendances du paquet ; elle n'applique pas
automatiquement le verrou. Aucune migration des rapports v0.2.0 n'est requise.

## Validation et fichiers téléchargeables

- 132 tests réussis sous Windows / Python 3.11, avec les dépendances verrouillées.
- Tests GitHub Actions sous Linux / Python 3.10 et Windows / Python 3.12.
- Paquet construit et installé, démo hors ligne et export PNG vérifiés.
- Wheel, archive source et archive des résultats de la démo.
- `SHA256SUMS.txt` fournit les empreintes des trois archives téléchargeables.

Les scores restent heuristiques et les projections 3D ne sont pas des structures
atomiques validées. L'ouverture par `--manifest` relève de la roadmap v0.3.0.
