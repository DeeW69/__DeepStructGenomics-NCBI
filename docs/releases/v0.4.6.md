# DeepStructGenomics-NCBI v0.4.6

Cette release regroupe deux commits dédiés : **v0.4.5**, benchmark ARN expérimental
avec ViennaRNA exécuté, et **v0.4.6**, analyse Hi-C avancée et documentation clarifiée.
Elle inclut les fonctionnalités déjà publiées en v0.4.4.

## v0.4.5 — Benchmark ARN

- 30 références dérivées de structures expérimentales PDB dans bpRNA-1m.
- Sélection déterministe avant prédiction, séquences uniques, provenance et SHA-256.
- Exécution de ViennaRNA 2.7.2 à 37 °C, comparaison avec Nussinov et témoins.
- Résultats archivés : F1 micro **0,6211** pour Nussinov, **0,8371** pour ViennaRNA.
- Structures, paramètres et énergies conservés pour la reproduction.

Le petit corpus ne couvre ni pseudonœuds ni diversité complète des familles ARN ;
aucune performance générale ou clinique n'est revendiquée.
Voir [le benchmark et ses limites](v0.4.5.md).

## v0.4.6 — Hi-C avancé

- Équilibrage symétrique à visibilité égale, masquage des bins sans couverture et
  diagnostic explicite de convergence. Aucun test aval si l'équilibrage échoue.
- Boucles candidates par modèle binomial négatif avec fond par distance/biais,
  estimation hors pixel testé et correction Benjamini-Hochberg.
- Frontières par score d'isolation, permutations par distance, q-values et
  segmentation en domaines candidats.
- Reconstruction par distances de contacts, plus courts chemins et MDS classique ;
  coordonnées en unités arbitraires, stress et diagnostic spectral.
- Exports JSON, Markdown, TSV, BED et figure PNG. Les composantes déconnectées ne
  sont pas reliées artificiellement.

L'exemple synthétique de 32 bins retrouve la frontière au bin 16 et la boucle 5–10.
Ces résultats vérifient la chaîne logicielle, pas sa validité sur un corpus Hi-C
expérimental. Les modèles statistiques ne garantissent pas une FDR biologique
calibrée ; la reconstruction n'est pas une mesure physique. Voir
[le guide détaillé](../hic_analysis.md).

## Installation et exemples

Depuis le tag `v0.4.6`, Python 3.10 ou ultérieur :

```bash
python -m pip install --require-hashes --only-binary=:all: -r requirements-lock.txt
python -m pip install --require-hashes --only-binary=:all: -r requirements-research-lock.txt
python scripts/evaluate_rna.py --reference data/benchmarks/bprna_pdb.json --viennarna --output outputs_benchmark/metrics.json
python scripts/explore_hic.py --contacts data/examples/hic_region.tsv --assembly synthetic --bin-size 10000 --advanced --chromosome chrSynthetic --start 0 --end 320000 --missing-as-zero --output-dir outputs_hic_advanced
python -m pytest
```

ViennaRNA/SciPy sont facultatifs pour les usages historiques. L'extra de paquet
`research` les déclare ; les verrous restent la procédure reproductible.
Le mode Hi-C avancé exige un **nouveau dossier**, une région cis explicite d'au plus
400 bins et des comptes bruts entiers. `--missing-as-zero` signifie que les pixels
absents sont des zéros observés, pas des données filtrées ou inconnues.

## Documentation et compatibilité

README recentré sur les commandes et résultats ; détails déplacés dans
`docs/pipeline.md` et `docs/hic_analysis.md`. VERSIONING.md décrit les six incréments,
les deux publications globales et les contrôles scientifiques de publication.
Les anciennes interfaces de séquence unique, lot FASTA et Hi-C descriptif restent
disponibles. L'évaluation ARN ajoute des champs de prédictions et provenance sans
retirer les métriques existantes. Aucune modification du verrou principal.
